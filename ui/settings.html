MCP Tools

    Bash Output Compression

    Compresses Bash tool outputs before they reach the LLM. Each filter is applied to every Bash output across all turns; transformations are semantically lossless (formatting only).

    Tool-Call Argument Referencing

    Past the Tool-Results time horizon, large tool-call arguments (Bash commands, MCP payloads) are replaced with a get_vt_object(hash) reference the model can pull back on demand. File tools (Read/Write/Edit) are left untouched. Small calls stay inline. This is a floor, not a switch: 0 is the most aggressive setting, not "off" — it removes the size gate so every call holding a string of 280+ chars is truncated. To turn referencing off, raise it above your largest call (20000 disables it in practice).
    chars (default 500 — the cache-study knee; 0 = truncate everything)

    Optimization Time Horizon

    How many recent turns each optimizer leaves untouched. Optimization applies only to messages older than the threshold. Lower values save more tokens but may strip context the model still needs.

    Claude Code

    Makes Claude Code use Voitta Desktop for your user, in every project and window: its LLM requests, its MCP tools, and the /llm, /voitta-store and /mcp commands.
    Claude Code reads its user settings from ~/.claude/settings.json and keeps user-level MCP servers in ~/.claude.json (where claude mcp add -s user writes). Configure Claude changes both through the same rules Claude Code uses, and keeps everything else in them. New Claude Code windows pick the changes up.

    /llm, /voitta-store and /mcp in Claude Code
